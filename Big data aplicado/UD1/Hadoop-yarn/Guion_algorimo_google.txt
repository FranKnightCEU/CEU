Un excelente ejemplo más avanzado y con gran aplicación real en Big Data es el Índice Invertido (Inverted Index) [2, 3]. Es la estructura de datos fundamental que utilizan los motores de búsqueda como Google o ElasticSearch para indexar documentos.
¿Por qué es un caso más complejo y educativo?
Acceso a Metadatos del Sistema de Archivos (FileSplit): El Mapper no solo lee el texto de la línea, sino que consulta a la infraestructura de MapReduce para saber en qué archivo específico de HDFS se encuentra esa línea [2, 10].
Múltiples Archivos de Entrada: Procesa varios archivos a la vez en HDFS (por ejemplo, El Quijote, Moby Dick y Frankenstein) [8, 9, 10].
Agregación con Estructuras Java (HashSet): El Reducer utiliza un conjunto para eliminar duplicados y construir una lista separada por comas de todos los libros donde aparece cada palabra.
📝 1. Código Fuente Java (InvertedIndex.java)
Guarda este archivo en tu máquina local como InvertedIndex.java:
import java.io.IOException;
import java.util.HashSet;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.input.FileSplit;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class InvertedIndex {

    // 1. MAPPER: Extrae el nombre del archivo origen y emite (palabra, nombre_archivo)
    public static class IndexMapper extends Mapper<LongWritable, Text, Text, Text> {
        private Text wordKey = new Text();
        private Text docValue = new Text();

        @Override
        public void map(LongWritable key, Text value, Context context) throws IOException, InterruptedException {
            // Obtener el nombre del archivo actual en HDFS usando FileSplit
            FileSplit fileSplit = (FileSplit) context.getInputSplit();
            String fileName = fileSplit.getPath().getName();
            docValue.set(fileName);

            // Limpieza del texto y division en palabras
            String line = value.toString().replaceAll("[^a-zA-Z0-9\\s]", "").toLowerCase();
            String[] words = line.split("\\s+");

            for (String w : words) {
                if (!w.trim().isEmpty()) {
                    wordKey.set(w);
                    context.write(wordKey, docValue);
                }
            }
        }
    }

    // 2. REDUCER: Desduplica los nombres de archivo y emite (palabra, "doc1.txt, doc2.txt")
    public static class IndexReducer extends Reducer<Text, Text, Text, Text> {
        private Text result = new Text();

        @Override
        public void reduce(Text key, Iterable<Text> values, Context context) throws IOException, InterruptedException {
            HashSet<String> uniqueDocs = new HashSet<>();

            // Agrupar y desduplicar archivos para la palabra clave
            for (Text val : values) {
                uniqueDocs.add(val.toString());
            }

            // Construir la cadena delimitada por comas
            StringBuilder docList = new StringBuilder();
            for (String doc : uniqueDocs) {
                if (docList.length() > 0) {
                    docList.append(", ");
                }
                docList.append(doc);
            }

            result.set(docList.toString());
            context.write(key, result);
        }
    }

    // 3. DRIVER: Configuracion del trabajo en YARN
    public static void main(String[] args) throws Exception {
        if (args.length != 2) {
            System.err.println("Uso: InvertedIndex <directorio_entrada_hdfs> <salida_hdfs>");
            System.exit(-1);
        }

        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Indice Invertido");

        job.setJarByClass(InvertedIndex.class);
        job.setMapperClass(IndexMapper.class);
        job.setReducerClass(IndexReducer.class);

        // Tipos de salida del Mapper y Reducer (Text, Text)
        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(Text.class);

        // Asignacion de rutas HDFS con los indices de args
        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
📋 2. Guía de Comandos Paso a Paso (PowerShell)
Para probarlo con múltiples archivos de entrada, utilizaremos los libros de las fuentes (pg11.txt, pg84.txt, pg2701.txt) [8, 9, 10]:
Paso 0: Limpieza preventiva de la sesión
docker exec -it hdfs-namenode hdfs dfsadmin -safemode leave
docker exec -it hdfs-namenode hdfs dfs -rm -r -f /output_index
docker exec -it yarn-resourcemanager rm -f /tmp/InvertedIndex.java /tmp/invertedindex.jar /tmp/InvertedIndex*.class
Paso 1: Subir varios archivos de texto a la carpeta /input de HDFS
# Asegurar el directorio de entrada
docker exec -it hdfs-namenode hdfs dfs -mkdir -p /input

# Subir tres libros distintos
docker cp pg11.txt hdfs-namenode:/tmp/alice.txt
docker cp pg84.txt hdfs-namenode:/tmp/frankenstein.txt
docker cp pg2701.txt hdfs-namenode:/tmp/moby_dick.txt

docker exec -it hdfs-namenode hdfs dfs -put -f /tmp/alice.txt /input/
docker exec -it hdfs-namenode hdfs dfs -put -f /tmp/frankenstein.txt /input/
docker exec -it hdfs-namenode hdfs dfs -put -f /tmp/moby_dick.txt /input/
Paso 2: Copiar, compilar y empaquetar el código Java
docker cp InvertedIndex.java yarn-resourcemanager:/tmp/InvertedIndex.java
docker exec -it yarn-resourcemanager bash
Dentro de la terminal del contenedor Linux:
export HADOOP_CLASSPATH=$(/opt/hadoop-3.2.1/bin/hadoop classpath)
javac -classpath "$HADOOP_CLASSPATH" -d /tmp /tmp/InvertedIndex.java
cd /tmp && jar cf invertedindex.jar InvertedIndex*.class
exit
Paso 3: Ejecutar el trabajo MapReduce sobre todo el directorio /input
docker exec -it yarn-resourcemanager yarn jar /tmp/invertedindex.jar InvertedIndex /input /output_index
Paso 4: Consultar los resultados del Índice Invertido
docker exec -it hdfs-namenode hdfs dfs -cat /output_index/part-r-00000 | select -first 30

📌 ¿Cómo explica Google el Índice Invertido a los Alumnos?
La Analogía del Índice de un Libro (Índice Invertido vs. Directo):
Índice Directo (Forward Index): Es como leer un libro entero de principio a fin para ver en qué páginas aparece la palabra "Hadoop". Si tuviéramos que buscar entre miles de millones de páginas web de esta forma, cada consulta tardaría horas.
Índice Invertido (Inverted Index): Es exactamente como el índice alfabético que aparece al final de un libro de texto. Mapea cada palabra clave con la lista de todas las páginas web donde aparece esa palabra. Gracias a esto, la búsqueda pasa de tardar minutos a ejecutarse en milisegundos.
La Estructura Interna: La Posting List (Lista de Publicaciones): En el motor de Google, el índice invertido no solo guarda los IDs de las páginas (DocID), sino que guarda metadatos clave en cada entrada:
Frecuencia del Término (Term Frequency - TF): Cuántas veces aparece la palabra en la página.
Posición u Offset: En qué carácter o número de palabra exacta está. Esto le permite a Google saber si dos palabras están juntas (para búsquedas de frases como "Big Data") y para generar el resumen (snippet) que ves en los resultados.
Etiquetas/Campos: Dónde aparece la palabra (si está en el título, en un encabezado <h1> o en el texto normal).
¿Cómo se conecta con MapReduce y el Ranking?
Fase de Construcción (MapReduce): Google utiliza trabajos de MapReduce distribuidos para analizar petabytes de páginas web rastreadas y construir estas Posting Lists de forma masiva y paralela.
Fase de Consulta y Combinación: Cuando un alumno busca "Hadoop MapReduce", Google toma la lista de la palabra "Hadoop" y la de "MapReduce", realiza la intersección rápida de ambas listas y finalmente ordena los resultados combinando la relevancia léxica con PageRank (la autoridad y enlaces entrantes de la página).
Temas clave identificados:
Indexación Estructurada: Mapeo de términos hacia documentos en lugar de documentos hacia términos.
Enriquecimiento de Metadatos: Almacenamiento de posiciones y frecuencias para búsquedas de frases y generación de fragmentos (snippets).
Escalabilidad Distribuida: Construcción paralela de índices a escala de petabytes mediante infraestructuras estilo MapReduce.
